Homework Planner

End-to-End Encrypted Agenda

View on GitHub ← Back to Projects

Homework Planner is a full-stack, end-to-end encrypted scheduling application built to keep student data private by design. The server never sees unencrypted data, so assignments, deadlines, and notes stay visible only to the person who created them.

The app supports syncing across devices, so a schedule stays up to date whether it's opened on a phone, tablet, or laptop, and it can import existing schedules from different formats instead of requiring everything to be entered by hand.

Highlights

  • End-to-end encryption, so the server never has access to plaintext data
  • Cross-device syncing to keep schedules consistent everywhere
  • Import support for bringing in existing schedules from other formats
  • Built with privacy and accessibility as core design goals, not afterthoughts
